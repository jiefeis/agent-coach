## 按症状查文件（排错速查表）
日常使用遇到报错或结果不对，直接对项目 AI 说 **`帮我查哪步错了`**，或按下面症状对照查看对应文件：

| 常见症状 | 第一时间看哪个文件 | 大概率是哪一步 | 怎么处理 |
| :--- | :--- | :--- | :--- |
| 换了新数据后程序报错/认不出输入 | `inputs\01-认出输入\` 与 `work\01-认出结果.md` | 第 1 步（认出输入） | 对照 `docs\run-flow.md` 输入清单核对文件名或表头栏目 |
| 中间算出来的数字、差值或筛选结果不对 | `work\NN-...\ ` 对应步骤产出文件 | 第 N 步（`scripts\NN_*.js`） | 打开该 `work\` 文件看哪行对不上，对 AI 说"帮我查哪步错了" |
| AI 写的文字口径、总结语气不对 | `docs\tickets\NN-*.md` 或 `AGENTS.md` | 对应 `AI看情况` 步骤 | 直接告诉 AI 改口径，并说"以后都要这样"写入规矩 |
| 流程顺序或人工停点需要调整 | `docs\run-flow.md` | 流程编排层 | 改完运行表后说"同步改动"让图和票对齐 |
