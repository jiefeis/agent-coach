## 按症状查文件（排错速查表）
日常使用遇到报错或结果不对，直接对项目 AI 说 **"帮我查哪步错了"**，或按下面症状对照查看对应文件：

| 常见症状 | 第一时间看哪个文件 | 大概率是哪一步 | 怎么处理 |
|---|---|---|---|
| 换了新数据后程序报错/认不出输入/提示多份文件 | `inputs\01-认出输入\` 与 `work\01-认出结果.md` | 第 1 步（认出输入） | 移走 `inputs\` 里残留的上周旧表，对照 `docs\run-flow.md` 核对文件名与表头 |
| 报“发现未知状态/枚举值”或原件混入脏格式 | `work\01-*` 或 `work\02-标准数据\` | 输入识别 / 数据清洗步 | 偶发脏点在源头另存干净副本，保留原件；若是业务新增固定状态，告知 AI 归属规则后更新票据 |
| 中间算出来的数字、差值或筛选结果不对 | `work\NN-...` 对应步骤产出文件 | 第 N 步（`scripts\NN_*.js`） | 打开该 `work\` 文件看哪行对不上，对 AI 说"帮我查哪步错了" |
| AI 写的文字口径、总结语气不对 | `docs\tickets\NN-*.md` 或 `AGENTS.md` | 对应 `AI看情况` 步骤 | 直接告诉 AI 改口径，再说"以后都要这样"写入规矩 |
| 需要增删步骤（如加清洗步）、改流向或调人工停点 | `docs\run-flow.md` 与 `docs\run-flow.html` | 流程编排层 | 先改 `docs\run-flow.md`，再说**"同步改动"**让流程图和工单票一起重排对齐 |
