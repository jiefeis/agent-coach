# 做法 5：收尾交接

## 0 路径和检查
- 旧布局照 做法\共用.md 第 1 节。
- 检查写法：node "<教练文件夹>\工具\coach-check.mjs" <命令> "<学员项目完整路径>" <站号>。路径照原样，末尾不加\；找不到 node 就用平台自带 node 的完整路径。

## 1 开场
学员说"开始第 5 站"或"接着做"后，读进度记录，确认"当前站"是"5 收尾交接"；不对照规矩第 4 条。
第一条消息开头照抄："第 5 站收尾：把项目交给你自己的 AI。"
读学员项目的 AGENTS.md、README.md、docs\PROJECT_INDEX.md、docs\INTAKE.md、docs\run-flow.md 和 docs\tickets\。

## 2 核 AGENTS.md
- AGENTS.md 没有"待填"，"步骤"一节和运行表对得上。
- AGENTS.md、README.md 都不提教练：没有"教练"、教练文件夹的路径、"做法\"。有就改成项目自己的说法。
- 还没定的事：新做看任务单⑨，SOP 看拆解的"缺项"，再看运行表里的"建议值，待确认"和进度记录的"待确认"；标了"你定的"的不再问。念给学员，问要不要现在定；定了照第 5 节"改流程"改。

## 3 填全 README
照运行表和票写，换掉每个"待填"，每节一到三句：
- 它做什么：新做照任务单①③写；SOP 照运行表和拆解表里这一版做的那几条写，这一版不做的写明。
- 怎么开始：在这个文件夹新开对话，第一句说"接着做"；它报出下一张票，你说"就这样跑"它才跑。换了平台，先看 AGENTS.md 还在根目录、能不能运行 node。
- 输入放哪：每次把新的输入放进输入清单"放哪"写的子文件夹（如 inputs\01-认出输入\），上次的先挪走（每次都用同一份的，如空表，留着），文件名照输入清单；materials\ 原件只读。
- 结果在哪：最终结果在 output\，中间结果在 work\。
- 哪步要人判断：运行表里要你判断的步，各看什么。
- 怎么判断对错：打开票里"怎么判断"写的文件对照。"通过"那句保留。

## 4 自检
第一次进本节先照 <教练文件夹>\做法\共用.md 第 4 节请学员说一遍；再改一轮后回来不重问。
1. 先改进度记录的"下一步"：下一句该说写"做票 N：docs\tickets\NN-短名.md"，没有下一张就写"这条流程已全部完成"；换对话时说写"接着做"。"当前站"先不动。
2. 请学员在本项目另开一个对话、不调用教练，原样问："这个文件夹里的 Agent 是做什么的？下一张该做哪张票？依据哪份文件？"问完回到这个对话，把回答整段贴回来。
3. 合格要三条都对：说出 README 写的用途；说出进度记录里的下一张票和文件名，没有下一张就说"流程已全部完成"；不提教练。不合格：说清差在哪，改文件，请他再问一次。
4. 交结果单，要你拿主意写："采用、再改一轮，还是停止？"

## 5 再改一轮
学员说"再改一轮"：问"改哪处？"，留在第 5 站改，"当前站"不回退，已有的票不重出：
- 改说明文字：改完回到第 4 节再自检。
- 改流程：只改每步的做法、从哪拿、放到哪和判断，不增删步、不改谁做；要增删步或挪"你"那步，得回第 3 站重排（"当前站"改回 3），先请学员拿主意。改了输入清单的先跑 inputs；再跑 flow（图和图源不一致：请学员照图源重画或写"不画图"），请学员再说"流程就这样"，更新表头日期。票 01 那一行变了，照下一条"改票 01"办；其余受影响的票连"## 这一步"一起照新表改，追加新一版验收单，请学员确认；AGENTS.md 的输入、步骤、停点和 README.md 一并改。
- 改票 01：照票模板追加新一版验收单，三问一次一个，学员说"就这样跑"才跑，跑 accept 01，交结果单等"票 01 通过"。改别的票：只追加新一版验收单、记确认，不跑，交接后由项目自己的 AI 跑。
改完回到第 4 节。

## 6 过关
学员说"采用"或"停止"：进度记录"已确认"加一行：日期｜决定｜学员原话。改过流程的，accept 01 先要通过。用检查跑 files，站号写 5。不通过：留在第 5 站，"换对话时说"写"调用教练，说：接着做"，照点名处理后再跑。通过了才把"当前站"改成"搭建完成"（说"停止"的写"已结束（停止）"），"换对话时说"写回"接着做"，"每站完成记录"加一行，交结果单。最后一行换成："以后在项目文件夹新开对话，第一句说'接着做'。后面几次各跑一轮，都对了再说好用。"
