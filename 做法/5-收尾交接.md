# 做法 5：收尾交接

## 0 路径和检查
- 旧布局照 做法\共用.md 第 1 节。
- 检查：node "<教练文件夹>\工具\coach-check.mjs" <命令> "<学员项目完整路径>" <站号>，末尾不加\；缺node用平台自带完整路径。

## 1 开场
“同步改动”照 共用.md 第5节，回原停点，不再问开始、不跑票或升站。
"开始第 5 站"或"接着做"：读进度，当前站不是5照规矩第4条。
第一条消息开头照抄："第 5 站收尾：把项目交给你自己的 AI。"
读学员项目的 AGENTS.md、README.md、docs\PROJECT_INDEX.md、docs\INTAKE.md、docs\run-flow.md 和 docs\tickets\。

## 2 核 AGENTS.md
- AGENTS.md 没有"待填"，"步骤"一节和运行表对得上。
- AGENTS.md、README.md 都不提教练：没有"教练"、教练文件夹的路径、"做法\"。有就改成项目自己的说法。
- 未定项：新做看任务单⑨，SOP看拆解"缺项"，再看表里"建议值，待确认"和进度"待确认"；"你定的"不重问。念给学员问现在定吗；定了照第5节改流程。

## 3 填全 README
照表和票填全各节，各一至三句：
- 它做什么：新做照任务单①③写；SOP 照运行表和拆解表里这一版做的那几条写，这一版不做的写明。
- 怎么开始：本项目新开对话说"接着做"；报下一张票或待做人工步；AI票尚未准本版开跑才等"就这样跑"，教学定稿不算开跑许可，已有适用批准不重问。换平台核根AGENTS.md和node。
交接时照 共用.md 第5节说明“同步改动”并核已接入，不代记掌握。
- 输入放哪：新输入照清单"放哪"的子文件夹放；上次的先挪走（空表等固定输入留着），名字照清单；materials\ 原件只读。
- 结果在哪：最终结果在 output\，中间结果在 work\。
- 哪步要人判断：运行表里要你判断的步，各看什么。
- 怎么判断对错：固定回归按绑定样例/参数全核；本期核固定规则/本次参数，只排除样例专属期望，存在/格式/固定规则/授权/每次必核不能跳。缺依据只停依赖项；accept核新数据须纳入样例、新版确认。结果照票分记实跑、未跑、不适用及依据；"通过"那句保留。

## 4 自检
先照 共用.md 第4节核①②记录，只对未做项请学员说一遍；再改一轮或换对话不重问已做项。
1. 按运行表和实做记录写进度"下一句该说"：下一AI票号/路径，或待人工判断的步号/要求；全步骤含人工已证完成才写"流程已全部完成"。"换对话时说"写"接着做"，读回后再请开新对话，当前站不动。
2. 请学员在本项目新开对话、不调用教练，原样问："这个文件夹里的 Agent 是做什么的？下一步做哪张票或哪项人工判断？依据哪份文件？"回来把回答整段贴上。
3. 合格：用途照README；下一票/待人工步及依据和进度、运行表一致，全步骤做完才说完成；不提教练。未采用只答不跑。不合格说明差异、改文件、再问。
4. 交结果单，要你拿主意写："采用、再改一轮，还是停止？"

## 5 再改一轮
"再改一轮"：问"改哪处？"，留站5，当前站不回退、已有票不重出：
- 改说明文字：改完回第 4 节再自检。
- 改流程：只改每步的做法、从哪拿、放到哪和判断，不增删步、不改谁做；要增删步或挪"你"那步，得回第 3 站重排（"当前站"改回 3），先请学员拿主意。改了输入清单的先跑 inputs；再跑 flow（图不一致就用已有能力更新并核实际图，缺能力记图未完成），请学员再说"流程就这样"，更新表头日期。票 01 那一行变了，照下一条"改票 01"办；其余受影响的票连"## 这一步"一起照新表改，追加新一版验收单，请学员确认；AGENTS.md 的输入、步骤、停点和 README.md 一并改。
- 改票01：追加新验收版，照做法4核三要素，只问缺项；等"就这样跑"，原话记录读回后才跑，accept 01后交单等"票 01 通过"。其他票只追加验收版、记录读回仅定稿确认，不跑，交接后另核开跑权限。
验收单改版均先照做法4第3节过ticket语法门，再确认；改完回第4节。

## 6 过关
"停止"：立即停止原范围执行，不等files/accept。记日期｜决定/范围｜未完项｜原话/来源并读回；记录失败也不恢复执行，报未记妥。能写时当前站记"已结束（停止）"，不记完成、不补files ✓。
"采用"：原话/来源成功记下并读回后，改过流程先过accept 01，再跑files 5。失败留站5，"换对话时说"写"调用教练，说：接着做"，按点名修后再验。通过才把"当前站"改"搭建完成"，"换对话时说"写回"接着做"，加每站完成记录、交单。末行："以后在项目新开对话说'接着做'。后面几次各跑一轮，都对了再说好用。"
