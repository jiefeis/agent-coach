# 共用做法：归位、体检看图、同步改动

只读点名的节；路径写法照当站做法第 0 节。

## 1 归位（第 3 站，写完输入清单、跑 inputs 之前）
`materials\` 只是收件处：原件只读、不挪不删。归位＝照输入清单"放哪"，把每个输入的样例、反例从 `materials\` 复制一份进 `inputs\` 下那一步的子文件夹，文件名、内容不改：
- 子文件夹叫 `inputs\<两位步号>-<短名>\`，步号、短名照运行表里第一次用到这个输入的那一步（第 1 步固定是 `inputs\01-认出输入\`）。排运行表前拿不准的先归第 1 步，排好后对不上的改"放哪"、挪文件、再跑 `inputs`。
- 一个输入几步都用：只放最早那一步的子文件夹，一份就够，后面的步骤"从哪拿"写"输入 N"去读。要照着填的空表也算那一步的一个输入，一次一份。每次都用同一份，不挪。
- SOP、说明：不复制。每步各自的规矩写进运行表那一步的"做什么"（依据：SOP 第 X 条），每次都要守的写进学员 `AGENTS.md` 的"## 一直守的规矩"；原件留在 `materials\`。
- 目标已有同名文件：内容一样跳过，不一样停下问学员，不覆盖。样例被挪走了，从 `materials\` 再复制一份。
认不出 `materials\` 里哪份是哪个输入的，一次问一份："`materials\` 里的 <文件名> 是哪个输入的样例、哪一步用，还是不用的？请直接打字回答。"复制由你做，用平台的文件复制。旧布局（运行表"放哪"写着 `materials\`）：照旧表跑，不归位，不改表、票、程序；做法里的 `inputs\` 都读作 `materials\`，不复制；样例录错另删 `docs\check\materials-基线.txt`。要换新布局，回第 3 站重排，先请学员拿主意。

## 2 体检看图
`scan` 对可查看的图和外来图源只列事实、不判。你按四样念，每样一句、指到报告的行；这四样报告没列的不编：
- 分不清：泳道名或图例不是 你/AI/程序/文件（如后端、数据库）。
- 看不出先后：框上没有步号；有框没有出线（死胡同）；一框两步（名字里有"+"）。
- 照 SOP 或人的做法画：框名对不上运行表短名；有开发过程或状态字样。没有运行表的项目，说"没有运行表，图无法核"。
- `materials` 画错：`materials\` 直接连到步骤（每次的输入该在 `inputs\`）。
外来图源和不是照教练画的图：另读它和运行表逐行对，点名出入（几行合成一框、多出或少了的框、运行表没有的线、人工关口对不对得上），两边都写文件和行号。
每样只给一句改法："先补运行表，再照图源重画"或"`materials` 先归位再画"。

## 5 同步改动（各站、修复收尾与三级回退路由）
先读项目 `AGENTS.md` 的“同步改动”节，按改动范围走以下**三级回退路由**，同一句优先于普通后续门，不自动跑后续业务票、不自动升站：

| 改动级别 | 触发信号 | 必须同步的动作（何时回 Archify 与重拆票） |
|---|---|---|
| **L1 单票局部修补** | 步骤数、顺序、谁做、跨步输入输出路径均未变，仅调某步内部公式、阈值或 `AI看情况` 措辞 | **不重画流程图、不重拆票**：验收标准变化才升版对应 `docs\tickets\NN-*.md` 并跑 `ticket`。仅定稿票保持未获准运行；取得本版运行许可后才更新脚本/规则、重跑绑定基线回归和 `accept` |
| **L2 流程与契约变更** | ① 增删/合并步骤（如补入独立`清洗数据`步或`按清单查`）；② 改`谁做`或增减人工停点；③ 改跨步输入输出路径或文件名参数规则 | **必须回更主表 + 重画 Archify + 对齐工单票**：先改唯一主表 `docs\run-flow.md` 跑通 `inputs` 与 `flow` → 调 Archify 重生成 `docs\run-flow.html`（保 `delivery.json`）→ 按新步号派生/更新 `docs\tickets\NN-*.md` 跑 `ticket`，受影响的旧通过项标待重验 |
| **L3 架构边界跃迁** | 固定流程演变为“看查询结果再定下一步（边查边定）”、“每次清单不同”或“多角色异步多 Agent 接力” | **停止硬塞单表**：回对照 `做法\架构推荐表.md` 重评架构，建议拆成独立单闭环项目或切换推荐架构 |

补充执行准则：
- 旧项目没“同步改动”这一段，只有明确调用本功能/授权范围才参考模板最小合并同步段及入口/读取关系，不搬入五站门；保留原规矩，不 `init`、不引教练路径。
- 图的更新、校验与确认照项目 `AGENTS.md`“同步改动”节的图规则（回执用 `--out-dir docs/check/archify/<本轮图修订>`，保留 `delivery.json` 与上次可用图；缺源/工具或不能查看明确报图未完成，不擅自安装；无需改图只核仍一致）。
- 已停止项目默认只读列同步项，只有针对文件整理的明确授权才写，业务保持停止。有没做完的项在现有进度记已做/未做/下一步；重复触发无新变化报已一致，不改版本，返回原站尚未完成的动作。
