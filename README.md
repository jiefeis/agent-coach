# Agent Coach（Agent 搭建教练）

**带不写代码的人，按「五站法」把一件日常工作稳妥交给 AI。**

当前版本：**v1.13**（以 `agent-coach` 技能调用） · [下载完整技能包 (.zip)](https://raw.githubusercontent.com/jiefeis/agent-coach/main/releases/v1.13/agent-coach-v1.13-20261112.zip) · [SHA-256 校验清单](https://raw.githubusercontent.com/jiefeis/agent-coach/main/releases/v1.13/SHA256SUMS.txt)

## 为什么用 Agent Coach？

直接把模糊需求丢给大模型“凭感觉一次性生成”（vibecoding），最常遇到三个坑：**口径偷偷算错**、**换一份表格就崩**、**过两周想改规则完全找不到该动哪个文件**。

`agent-coach` 把搭建过程拆成有静态检查器（`coach-check.mjs`）兜底的**五站式工作流**：先把规则边界、文件流向和真值验收标准锁死，再分步生成确定性脚本或受控提示词，最后交还给项目自带的本地规矩独立运行。

## 五站流程与双档位

| 站号 | 阶段名称 | 核心动作与产出 | 过关口令 |
| :--- | :--- | :--- | :--- |
| **第 1 站** | 建项目 | 初始化项目规矩与目录，将真实脱敏样例（支持 `.xlsx` / `.pptx` / `.docx` / `.csv` 原件）放入只读 `materials\` | `项目建好了` |
| **第 2 站** | 说清需求 / 拆 SOP | 自动剥离半成品文档中的旧代码与噪音，输出带默认推荐项的确认单，按 8 类信号判定是否需要搭建 | `任务单确认` / `拆解确认` |
| **第 3 站** | 排表画图 | 物理归位输入样本，生成全项目唯一步骤主表 `docs\run-flow.md` 与可视化流程图 `docs\run-flow.html` | `流程就这样` |
| **第 4 站** | 一步一票 | 自动派票并预填真实样例校验值；支持**教学档**（逐票核对）与**快跑档**（纯脚本票绿灯连跑） | `票 N 通过` / `按快跑档推进` |
| **第 5 站** | 收尾交接 | 生成《按症状查文件速查表》，完成 30 秒看表指路演习，正式移交项目本地 AI | `采用` / `停止` |

另有独立分支：**项目体检与修复**（对任意已有项目进行只读静态扫描，按问题编号 `P01` 逐项授权修复与复诊）。

### 第 4 站双档位怎么选？

* **教学档（默认）**：适合零基础初建项目。每跑完一张票输出一张【文件定位卡】，亲眼核对一次中间产物与坏输入拦截结果后再进下一张。
* **快跑档（口令：`按快跑档推进`）**：适合教练操盘或熟手迭代。对已确认范围内、无人工停点的 `AI照规矩` 纯脚本票，只要静态断言与坏输入测试全绿就自动连续跑通；一旦遇到断言失败、`AI看情况` 主观判断步或删改外发红线立即停下汇报。

## 四重文件定位锁（防黑盒设计）

为了避免跑通交付后“不知道哪步出错、不知道去哪改文件”，生成出的每个项目都自带四层定位机制：

1. **物理一步一档**：严格保持 `scripts\NN_短名.js`、`work\NN-中间结果`、`docs\tickets\NN-短名.md` 编号一一对应，绝不混成单文件大黑盒。
2. **每步文件定位卡**：每次跑票固定展示“读了谁 → 写了谁 → 真值抽样 → 以后这类问题改哪个文件”。
3. **README 症状速查表**：在生成项目的 `README.md` 内固化“换表报错看哪、数字算错查哪个 `work\` 文件、改文风动哪张票”的对号入座表。
4. **内置自诊口令**：日常使用遇到报错或结果不符，直接对项目 AI 说 **`帮我查哪步错了`**，AI 会顺着 `inputs\ -> work\01..N -> output\` 逐级核对并报出第一处出错的步骤与文件。

## 快速安装与常用口令

### 3 步安装（以 WorkBuddy 为例）

1. 下载上方的 `agent-coach-v1.13-20261112.zip`（保持原 ZIP，无需解压重打包）。
2. 在 WorkBuddy「技能管理 → 添加技能 → 上传技能」中上传该 ZIP 包。
3. 打开你自己的空项目文件夹，切到 **Agent** 模式并勾选 `agent-coach` 技能即可开聊（在 Claude Code / Codex 中同样可直接加载本技能目录）。

### 常用口令速查

| 场景 | 你直接对 AI 说的话 |
| :--- | :--- |
| 从零开始搭新项目 | `调用 agent-coach，带我开始新项目。` |
| 跨对话恢复搭建进度 | `调用 agent-coach，接着做` |
| 诊断已有项目（只读不改） | `调用 agent-coach，体检当前项目，先不修复。` |
| 按体检报告定向修复 | `修复 P01` |
| 第 4 站开启纯脚本连跑 | `按快跑档推进` |
| 修改规则后对齐流程图与票据 | `同步改动` |
| 交付后日常排查哪里算错 | `帮我查哪步错了`（直接对项目自身 AI 说，无需调教练） |

## 运行环境与试用说明

* **运行环境**：当前面向 Windows 路径规范设计，需可用 **Node.js 22 或 24**（WorkBuddy 自带运行环境；`工具\coach-check.mjs` 为零外部依赖原生脚本）。
* **安全边界**：`materials\` 原件全程只读保护；涉及对外发送、付款、删除 `materials` / `work` / `output` 文件的操作一律交由人工执行。
* **试用提示**：静态检查器通过代表文件契约与断言核对一致，涉及模型主观生成的步骤仍请结合业务证据审阅确认。

在 Git 仓库根目录运行 `.\工具\pack-release.ps1` 可重建安装包和校验清单，输出在 `releases\v1.13\`。
