# Agent 搭建教练

## 这是什么
这是一个 AI 技能。装好后，在你自己的项目文件夹里调用它，AI 就会一站一站带你，把你的一件工作交给 AI 来做。你不用写代码。
一共五站：建项目、说清需求、排表画图、一步一票、收尾交接。走到"第一步练习完成"为止：你的第一个真实样例，第 1 步（认出输入）通过。
装之前先用浏览器打开解压出来的 讲解\五站总览.html，看五站各做什么。

## 第 0 步：先设置
1. WorkBuddy 在设置里关掉"本地技能与记忆沉淀"。培训完可以再打开。
2. 装 Archify 架构图生成器，第 3 站用它画流程图。
3. 装"拆分工单"（to-tickets），第 4 站用它拆票。已装 grill-me 的，培训期间先停用，停不了就照常用。
4. ponytail、verification-before-completion 可选，不装也能做。

## 怎么装
1. 右键 zip，选"全部解压"。解压出的文件夹里，第一眼能看到 SKILL.md 和 README.md。
2. 把这个文件夹改名成 agent-coach，整个放进你平台的技能目录（见下面"各平台"）。不套外层文件夹：技能目录\agent-coach\SKILL.md 正好在这一层。
3. 升级：先删掉旧的 agent-coach 文件夹，再放新的。同一个技能别装两份。你的项目不受影响。

## 怎么用
1. 新项目：先建一个自己的项目文件夹（放哪都行），用它当工作空间打开；原始材料可以先放进它的 materials\。第一句调用教练，说"带我开始新项目"，不说"你好"。
2. 弹出"越权确认"时，点"本次会话内始终允许"。每个新对话第一次读教练文件夹或写你的项目时，可能再弹一次。
3. 以后接着做：在这个项目里新开对话，调用教练，说"接着做"。
4. 体检已有项目：另开一个空的工作空间（不是被体检的那个项目），调用教练，说"帮我体检 <文件夹完整路径>"。报告写在这个工作空间的 体检\<项目名>\ 里。
5. 别把项目建在技能文件夹里。技能文件夹只读，你自己的文件都放在项目文件夹。

## 各平台怎么装、怎么调用
- 目前只支持 Windows 电脑，电脑上要能运行 node（WorkBuddy 自带；别的平台没有就先装 Node.js）。
- WorkBuddy：主要平台，验收还没做完。"专家·技能·连接器 → 技能 → 添加技能 → 上传技能"选原 zip；用"做一做"模式，工作空间选你的项目文件夹，不用"问一问"；在输入框"+ → 技能"里选 agent-coach。
- Codex：未验（技能装法还没实测）。放进 %USERPROFILE%\.agents\skills\agent-coach\（有的版本也认 .codex\skills，二者只装一处）；打开你的项目文件夹，用技能选择器点名 agent-coach。
- Claude Code：未验（技能装法还没实测）。放进 %USERPROFILE%\.claude\skills\agent-coach\；在你的项目文件夹启动，打 /agent-coach。先看 ~/.claude/CLAUDE.md 里有没有和教练冲突的规矩。
- 豆包工作：实测过第 1、2 站和体检。技能管理里"安装 → 上传技能"选原 zip；在项目里新开对话，用输入框的"/"或"更多技能"选它（显示为 Agent Coach），不是 @。

## 以前把教练包当项目打开做过的
装好技能后，用那个项目文件夹当工作空间打开，调用教练，说"接着做"。不重新建，材料不用挪。

## 版本
教练第一句会报版本。你的项目里 docs\PROJECT_INDEX.md 也记着版本。
