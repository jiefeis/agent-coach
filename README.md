## 接着做时读什么

| 核心文件 | 职责 |
| --- | --- |
| 项目 `AGENTS.md` 或已有规则入口 | 稳定规则、读取入口及适用边界。 |
| `docs/PROJECT_INDEX.md` 或项目已有进度记录 | 当前任务、决定、文件地图、证据、未完项与下一动作。 |
| 已有 workflow / run-flow / SOP | 流程步骤、输入输出、责任人和人工停点。 |
| 当前票或任务记录 | 本步输入输出、验收、适用确认及实际结果。 |

README 负责使用与交接说明。保留项目已有文件名和格式；平台记忆只作索引，开工仍沿入口及当前步骤的引用实际读取。文件在场、只登记目录或模型记得内容，都不等于资料已经连接。独立规则确有需要才建立，并登记用途、适用步骤和谁先读。

推进顺序是：定位未完任务 → 核输入及适用决定 → 执行已授权下一步 → 验证 → 同步资料、证据和返回点。已有同版、同范围的适用批准不重复询问；缺输入、新决定或人工关口只停依赖动作。最新决定说明该做什么，实际文件、检查和人工判断说明做到哪里，不能只凭完成标签重建或重跑。

修复后做针对性验证，核受影响资料及读取引用同版，保留旧确认与证据，再接回原未完动作或人工关口。材料原件只读，原验收和授权边界继续有效。
